# EKLT {#mainpage}

EKLT provides the original ROS1 event-based KLT tracker together with a
ROS-free event reconstruction core and experimental ROS2 integration.

Start with the repository README and the
[usage guide](USAGE_GUIDE.md). Focused native, wrapper, and event-only guides
are added with their corresponding implementation batches.

The wrapper API uses Eigen matrices and vectors through the shared gtwrap
interface. Python targets version 3.12 or newer, and MATLAB targets R2024b.
